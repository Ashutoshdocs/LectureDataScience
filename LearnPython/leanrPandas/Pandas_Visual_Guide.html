pandas: Spreadsheets in Python

NumPy gave Python fast arrays of numbers. pandas builds on them to give you tables: named columns, labelled rows, mixed types, missing values, and tools to load, clean, filter, group and join real-world data.

This is a DataFrame. Tap any part of it to learn its name.

DataFrame: a whole table. Think of it as a spreadsheet you control with code, built from one Series per column, all sharing one index.
Step 1 · The building blocks

Series, DataFrame and Index

Every pandas object is made of three ideas. Picture a ledger book: the index is the row labels down the left margin, each Series is one labelled column, and the DataFrame is the whole page.

One column

Series

A single column of values, each with a label.

  • Values are a NumPy array: one dtype, fast maths
  • Labels come from the index
  • pd.Series([78, 92], index=["Asha", "Ravi"])
Like: one column of a spreadsheet, with its row names.
The whole table

DataFrame

Many Series side by side, sharing one index.

  • Each column has a name and its own dtype
  • Columns can differ: text, numbers, dates
  • pd.DataFrame({"name": [...], "marks": [...]})
Like: a whole sheet, or a database table.
Row labels

Index

The labels that identify each row.

  • Default: 0, 1, 2… (like row numbers)
  • Can be names, IDs, dates: anything unique-ish
  • Used to find rows and align data
Like: the row headers, or a primary key in a database.

From list to NumPy to pandas: each step adds something

Python list
[78, 92, 65]

Values in order. No types enforced, no labels, maths needs loops.

NumPy array
array([78, 92, 65])

Adds one dtype and fast vectorized maths. Still no names.

pandas Series / DataFrame
Asha     78
Ravi     92
Meena    65

Adds labels, named columns, missing-data handling and data tools.

Common mix-up: pandas doesn't replace NumPy; it's built on it. Every numeric column of a DataFrame is a NumPy array underneath (df["marks"].to_numpy()). So you keep NumPy's speed and gain labels.
Step 2 · Index & selection

Find data by label or by position

.loc finds rows and columns by their labels. .iloc finds them by integer position (0, 1, 2…). Pick a selection and watch which cells light up. The output is real pandas output.

Memory trick: iloc = integer location. And watch the slices: .loc["Asha":"Meena"] includes Meena, while .iloc[0:2] stops before position 2, like normal Python.

Alignment: labels keep your data honest

Two Series list the same items in a different order. pandas matches them by label; plain NumPy arrays just pair them by position.

The data
price = pd.Series([40, 25, 120], index=["tea", "bun", "pizza"]) qty = pd.Series([2, 4, 1], index=["pizza", "tea", "bun"])
price * qty
pandas ✓

tea = 40 × 4 = 160 ✓

NumPy ✗

40 × 2: tea's price × pizza's qty ✗

    Ask questions with conditions

    A condition like df["salary"] > 50000 gives a mask: one True/False per row. Putting the mask inside df[ ] keeps only the True rows. Build your own filter below.

    The mask column shows the True/False Series pandas builds. Faded rows are dropped. Notice that kept rows keep their original index labels.

    Step 7 · Popularity

    Why pandas is the default tool for data

    pandas sits in the middle of almost every Python data workflow: data comes in from files and databases, gets cleaned and analysed, and goes out to charts, machine learning and reports. Tap any box.

    pandas is the hub. Tap a source or a destination.
    • 2008Wes McKinney starts building pandas at the investment firm AQR Capital, to analyse financial data in Python.
    • 2009First public, open-source release (version 0.1, December).
    • 2012McKinney's book Python for Data Analysis spreads pandas to a wide audience.
    • 2020pandas 1.0, a sign of a stable, mature API.
    • 2023pandas 2.0 adds optional Apache Arrow-backed data types.
    • 2026pandas 3.0: text gets its own string dtype by default, and Copy-on-Write behaviour becomes standard.

    Reads everything

    CSV, Excel, JSON, SQL, Parquet, HTML tables: one function each.

    Cleans for you

    Built-in tools for gaps, duplicates, types and messy text, instead of hand-written loops.

    Reads like the question

    df.groupby("city")["sales"].sum() says exactly what it does.

    Fast enough

    Vectorized NumPy underneath handles millions of rows on a laptop.

    Repeatable

    A script re-runs next month on new data in seconds. A spreadsheet needs the same clicks again.

    Connects

    DataFrames plug straight into Matplotlib, seaborn, scikit-learn and Jupyter notebooks.
