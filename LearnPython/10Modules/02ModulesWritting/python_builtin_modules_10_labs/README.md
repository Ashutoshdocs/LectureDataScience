# Python Built-in / Standard-Library Modules — 10 Practical Labs

A beginner-friendly set of ten independent exercises that introduce useful Python modules that come with Python.

## Modules covered

1. `math` — mathematical functions and constants
2. `random` — random numbers, choices, samples, and shuffling
3. `datetime` — dates, times, formatting, and durations
4. `os` — operating-system and directory operations
5. `sys` — Python runtime information, arguments, and module search path
6. `pathlib` — object-oriented filesystem paths
7. `json` — convert Python data to and from JSON
8. `statistics` — mean, median, mode, variance, and standard deviation
9. `collections` — Counter, defaultdict, and deque
10. `re` — regular expressions for searching and validating text

## Requirements

- Python 3
- No third-party packages
- Internet connection not required

These are Python standard-library modules. They are included with Python and do not need to be installed using `pip`.

## How to practise

Each lab has its own folder containing:
- `lab.py` — runnable example
- `README.md` — teaching notes, code, explanation, run instructions, and practice task

Run one lab at a time. For example:

```bash
cd Lab_01_math
python3 lab.py
```

On Windows:

```powershell
cd Lab_01_math
py lab.py
```

## Suggested teaching order

Start with `math`, `random`, and `datetime` to learn useful functions. Continue with `os`, `sys`, and `pathlib` for system and file operations. Finish with `json`, `statistics`, `collections`, and `re`.

## Important note

The phrase “built-in modules” is commonly used in beginner teaching. More precisely, these examples use Python's standard library: modules bundled with Python. They are not all built-in modules in the strict interpreter-embedded sense.
