# Python File Handling — Teaching Lab

This archive follows the chapter and topic sequence in the supplied **Python File Handling Lab**.

## Structure
- One folder per chapter.
- One subfolder per topic/lesson.
- Each topic contains its Python files and the sample text/CSV/JSON data files used by that example.
- Every Python source line has an explanatory `#` comment immediately above it where Python syntax permits. Multiline string contents are kept intact so the program remains valid; their opening/docstring statements are explained.

## Requirements
- Python 3.9 or later is recommended.
- No third-party packages are required; the lessons use Python's standard library.

## How to study
1. Open a chapter folder and read its `README.md`.
2. Enter a topic folder.
3. Read that topic's `README.md`.
4. Run `python main.py` from that topic folder.
5. Read the comments alongside the code, inspect the output, and complete the practice suggestions.

Some topics create output files or folders when executed. Run each lesson from its own folder so the sample files remain organised.
