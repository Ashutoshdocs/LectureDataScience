# JSON basics: dumps and loads

**Chapter:** JSON files

## Learning objectives

Work through the Python examples in this folder. Each Python source line has an explanatory `#` comment immediately above it wherever Python syntax allows.

## Files in this topic

- `main.py` — Python example with line-by-line comments.

## How to run

1. Open a terminal in this topic folder.
2. Run the main example with:

   ```bash
   python main.py
   ```

3. If the topic contains helper Python files (for example `cleaner.py` or `dataset.py`), keep them in the same folder as `main.py`.
4. Read the comments from top to bottom, then change the sample data and run the program again.

## Practice

Try changing the input file, search keyword, values, or conditions and observe how the output changes.
