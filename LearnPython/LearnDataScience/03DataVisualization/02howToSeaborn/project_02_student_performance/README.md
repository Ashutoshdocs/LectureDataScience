# Project 2 — Student Performance EDA

Run from the toolkit root:
```bash
pip install -r requirements.txt
python project_02_student_performance/main.py
```

The synthetic student dataset contains course, study hours, attendance, completed assignments, sleep hours, and marks. The project creates a multi-variable scatter plot, violin plot, pair plot, correlation heatmap, and course summary.

Student tasks: add attendance as marker size, create an ECDF plot, compare course distributions, and discuss why study hours alone cannot explain marks.
