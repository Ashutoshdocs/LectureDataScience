# Project 2: Monthly Sales Analysis

## Folder structure
- `data/sales.csv`: product-by-month unit sales
- `code/main.py`: reads the CSV and performs analysis using NumPy
- `code/requirements.txt`: Python dependency

## Run
From this project folder:

```bash
python -m pip install -r code/requirements.txt
python code/main.py
```

The CSV stores units sold, not revenue. The script locates the CSV relative to its own file.
