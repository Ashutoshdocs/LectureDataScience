# Project 1: Student Performance Analyzer

## Folder structure
- `data/students.csv`: student names and marks
- `code/main.py`: reads the CSV and performs analysis using NumPy
- `code/requirements.txt`: Python dependency

## Run
From this project folder:

```bash
python -m pip install -r code/requirements.txt
python code/main.py
```

The script locates the CSV relative to its own file, so it can be run from any working directory.
