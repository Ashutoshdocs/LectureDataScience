# NumPy CSV Projects

This ZIP contains two independent projects. Each project has:
- a `data` folder containing its CSV input file
- a `code` folder containing the Python program and requirements

## Projects
1. `project_1_student_performance` — analyze student marks.
2. `project_2_sales_analysis` — analyze monthly product unit sales.

Install NumPy for each project (or once in your active Python environment):

```bash
python -m pip install numpy
```

Run a project from the extracted folder:

```bash
python project_1_student_performance/code/main.py
python project_2_sales_analysis/code/main.py
```
