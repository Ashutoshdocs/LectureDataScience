# 04 — Classification: Predict Categories

Classification predicts labels such as spam/not spam or a flower species.

Programs:
- `01_iris_logistic_regression.py`: Logistic Regression on sklearn's built-in Iris dataset.
- `02_decision_tree.py`: Decision Tree on the built-in breast-cancer dataset.

Run each script. Explain accuracy, precision, recall, F1-score, and the confusion matrix. Practice changing test size and tree depth. Accuracy alone may be misleading when classes are imbalanced.
