# 03 — Regression: Predict Numbers

Regression is used for continuous numerical targets such as marks, house prices, demand, or delivery time.

Programs:
- `01_simple_linear_regression.py`: one feature.
- `02_multiple_regression.py`: multiple features.

Run both scripts with Python from the project root. Discuss why multiple regression can use study hours, attendance, and assignments together. Practice adding another feature and compare actual vs predicted values.
