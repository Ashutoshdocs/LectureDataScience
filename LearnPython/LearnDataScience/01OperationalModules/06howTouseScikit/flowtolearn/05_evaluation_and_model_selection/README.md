# 05 — Evaluation and Model Selection

Do not select a model based on one training score. Learn to measure and compare models.

Topics:
- Regression: MAE and R-squared.
- Classification: accuracy and detailed class metrics.
- Cross-validation: evaluate across multiple folds.
- `GridSearchCV`: try hyperparameter combinations systematically.

Run:
```bash
python 05_evaluation_and_model_selection/01_cross_validation.py
python 05_evaluation_and_model_selection/02_grid_search.py
```
Practice changing tree depth and comparing cross-validation scores. Keep a final test set separate from parameter tuning.
