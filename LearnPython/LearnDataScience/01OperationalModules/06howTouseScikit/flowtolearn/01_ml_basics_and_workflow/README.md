# 01 — ML Basics and First Model

**Why sklearn?** Instead of implementing a learning algorithm and training procedure ourselves, sklearn supplies tested algorithms with a consistent API.

Concepts: supervised learning, features X, target y, `fit()`, `predict()`, `train_test_split()`.

Run:
```bash
python 01_ml_basics_and_workflow/01_first_model.py
python 01_ml_basics_and_workflow/02_train_test_split_demo.py
```
Practice: change the test size; identify X and y; explain why test examples must not be used to train the model.
