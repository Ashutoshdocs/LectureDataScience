# Project 1 — Employee Analytics and Salary EDA

Run from the toolkit root:
```bash
pip install -r requirements.txt
python project_01_employee_analytics/main.py
```

The synthetic employee CSV is used to explore salary distributions, compare departments, inspect experience versus salary, and create a correlation heatmap. Outputs and logs are saved in this project's `output/` and `logs/` folders.

Student tasks: add location as `hue`, compare mean and median salary, add an ECDF plot, and explain why correlation does not prove causation.
