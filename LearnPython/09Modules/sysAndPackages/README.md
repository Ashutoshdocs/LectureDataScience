# Python Imports, sys.path, and Packages – Beginner Course

Complete the three folders in order:

1. `01_basic_import` – one main file imports two modules in the same folder.
2. `02_sys_path_different_folders` – use `sys.path` to import modules stored in a different folder.
3. `03_package_creation` – create a package with `__init__.py` and import its modules.

## Requirements
- Python 3
- No third-party libraries

## Run examples
Run each command from the course root:

```bash
python3 01_basic_import/main.py
python3 02_sys_path_different_folders/app/main.py
python3 03_package_creation/main.py
```

Each folder is self-contained and includes its own README with explanations and practice tasks.
