# Python Modules and Imports – Beginner Course

This ZIP contains five progressive folders. Work through them in order.

1. `01_standalone_programs` – two independent programs with repeated logic.
2. `02_shared_module_import` – move common functions into `common.py` and use `import common`.
3. `03_import_as_alias` – use `import common as helper`.
4. `04_from_import_functions` – use `from common import function_name`.
5. `05_main_guard` – introduce `main()` and `if __name__ == "__main__":`.

## Requirements
- Python 3
- No third-party packages

## How to run
Open a terminal, enter the folder you want to practise, and run the listed Python files:

```bash
cd 01_standalone_programs
python3 program1.py
```

For each later folder, change into that folder and run `program1.py` or `program2.py`.

Each folder is self-contained so you can practise it independently.
