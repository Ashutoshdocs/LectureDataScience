Once there was a small robot named Pixel.
Pixel lived in an old library in Pune.
Every night Pixel read one book.
It loved stories about the sea.
One day it found a dusty notebook.
The notebook had no title.
Inside were maps drawn by hand.
Pixel followed the first map.
It led to the library garden.
Under a mango tree was a box.
The box was locked with a code.
Pixel tried many numbers.
The code was the year the library opened.
Inside the box was a letter.
The letter said keep reading, keep learning.
Pixel smiled with its tiny screen.
It put the letter back in the box.
Then it returned to the shelves.
That night it read two books instead of one.
And Pixel never stopped reading again.
