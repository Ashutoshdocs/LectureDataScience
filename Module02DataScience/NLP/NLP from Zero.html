Lesson 01 · Foundations

What is NLP?

Natural Language Processing (NLP) is a branch of Artificial Intelligence that helps computers read, understand and produce human language, the kind we speak and write every day ("natural" language, as opposed to programming languages).

You already use NLP many times a day: your phone's autocorrect, Gmail sorting spam, Google Translate, voice assistants and chatbots like ChatGPT or Claude.

Why is it hard? Language is ambiguous. "I saw her duck" could mean you saw her pet bird, or you saw her bend down. "That movie was sick" is praise, not illness. Humans use context effortlessly; computers need to be taught.

Lesson 02 · Foundations

Text preprocessing

Real-world text is messy: CAPITAL letters, emojis, links, HTML tags, typos, extra spaces. Preprocessing means cleaning text so that the same idea always looks the same to the computer.

Analogy: washing and chopping vegetables before cooking. To a computer, "Movie", "movie" and "MOVIE!!!" are three different strings. After lowercasing and removing punctuation they become one word.

Common cleaning steps

  • Lowercasing: "Apple" → "apple"
  • Removing HTML tags & URLs: <b>NOW</b> → "NOW"
  • Expanding contractions: "can't" → "can not"
  • Removing punctuation, numbers, emojis (only if they don't matter for your task)
  • Fixing whitespace: collapsing many spaces into one

Careful: not every step suits every task. For sentiment analysis, "!!!" and 😍 carry emotion, so you might keep them. Preprocessing is a set of choices, not a fixed recipe.

Try it · toggle each step
Clean output
Python 
import re

text = "  OMG!!! I can't believe it 😍 Check https://shop.example.com <b>NOW</b>"
text = text.lower()                                  # lowercase
text = re.sub(r"<[^>]+>", "", text)                    # strip HTML tags
text = re.sub(r"https?://\S+", "", text)              # strip URLs
text = text.replace("can't", "can not")             # expand contraction
text = re.sub(r"[^a-z\s]", "", text)                 # keep only letters
text = re.sub(r"\s+", " ", text).strip()             # fix spaces
print(text)   # omg i can not believe it check now
Lesson 03 · Foundations

Tokenization

Tokenization splits text into smaller pieces called tokens. A token is the basic unit the model works with. It can be a word, a character, a sentence, or a piece of a word.

Analogy: breaking a LEGO model back into bricks so you can count, sort and rebuild them.
Word tokens

Split on spaces & punctuation.

"I love NLP!" → [I] [love] [NLP] [!]
Character tokens

Every letter is a token. Tiny vocabulary, very long sequences.

"cat" → [c] [a] [t]
Sentence tokens

Split a paragraph into sentences.

"Hi. Bye." → [Hi.] [Bye.]
Subword tokens

Used by modern models (BERT, GPT). Rare words break into known pieces.

"unhappiness" → [un] [##happi] [##ness]

Why subwords? A word tokenizer has never seen "unhappiness" if it wasn't in training data, so it becomes [UNK] (unknown). Subword tokenizers can still build it from familiar parts. The ## means "this piece continues the previous word".

Try it · switch tokenizer
Tokens
Python · NLTK 
import nltk
nltk.download("punkt")
from nltk.tokenize import word_tokenize, sent_tokenize

text = "I love NLP. It's fun!"
print(word_tokenize(text))  # ['I', 'love', 'NLP', '.', 'It', "'s", 'fun', '!']
print(sent_tokenize(text))  # ['I love NLP.', "It's fun!"]
Lesson 04 · Foundations

Stopwords

Stopwords are very common words like the, is, a, in, and, of. They appear in almost every sentence, so they usually tell us little about what a text is about. Removing them makes data smaller and lets important words stand out.

Analogy: a telegram. People paid per word, so "I am arriving at the station at 5" became "ARRIVING STATION 5". The meaning survives.

Warning: NLTK's English list includes not, no and nor. Remove them and "not good" becomes "good", which flips the meaning. For sentiment analysis, keep negations.

from nltk.corpus import stopwords

tokens = word_tokenize("the movie was not good")
print([t for t in tokens if t not in stop])   # ['movie', 'good']  ← meaning lost!
Lesson 05 · Foundations

Stemming and Lemmatization

"run", "runs", "running" and "ran" all describe the same action. Both techniques reduce words to a base form so the computer treats them as one.

Stemming · fast & crude

Chops off word endings with fixed rules (like the Porter stemmer). The result may not be a real word.

studies → studi
happiness → happi
ran → ran (rule can't see it)
Lemmatization · slower & smart

Uses a dictionary and grammar to find the true base word, called the lemma.

studies → study
better → good
ran → run
Analogy: stemming is cutting a branch with an axe at a fixed spot. Lemmatization is a gardener who knows the plant and finds its real root.

When to use which? Stemming for search engines and quick experiments with lots of data. Lemmatization when you need readable, accurate words (chatbots, analysis reports). Real lemmatizers also need the part of speech: "meeting" is a noun in "the meeting" but the verb "meet" in "I am meeting her".

Try it · compare side by side
OriginalStem (Porter-style)Lemma

Python · NLTK 
from nltk.stem import PorterStemmer, WordNetLemmatizer
nltk.download("wordnet")
ps, wnl = PorterStemmer(), WordNetLemmatizer()

print(ps.stem("studies"))              # studi
print(wnl.lemmatize("studies"))        # study
print(wnl.lemmatize("better", pos="a")) # good   (a = adjective)
print(wnl.lemmatize("ran", pos="v"))    # run    (v = verb)
Lesson 06 · Turning text into numbers

Bag of Words

Machine-learning models need numbers. Bag of Words (BoW) is the simplest way to get them:

  • Collect every unique word across all documents. This list is the vocabulary.
  • For each document, count how many times each vocabulary word appears.
  • Each document becomes a row of numbers called a vector.
Analogy: tip all the words of a sentence into a bag and shake it. You know which words are inside and how many, but the order is lost. That is why "dog bites man" and "man bites dog" get the identical vector.
Try it · edit the documents
Document-term matrix (word counts)

Limitations: word order is lost, the vectors become huge with large vocabularies (mostly zeros, called "sparse"), and common words dominate the counts. TF-IDF fixes that last problem.

Python · scikit-learn 
from sklearn.feature_extraction.text import CountVectorizer

docs = ["I love this movie", "I hate this movie"]
cv = CountVectorizer()
X = cv.fit_transform(docs)
print(cv.get_feature_names_out())  # ['hate' 'love' 'movie' 'this']
print(X.toarray())                 # [[0 1 1 1]
                                   #  [1 0 1 1]]
Lesson 07 · Turning text into numbers

TF-IDF

TF-IDF stands for Term Frequency × Inverse Document Frequency. It gives a word a high score when it is frequent in this document but rare in other documents. Such words describe the document best.

TF · Term Frequency

How often the word appears in this document.

TF = count of word ÷ total words in doc
IDF · Inverse Document Frequency

How rare the word is across all documents.

IDF = ln( N ÷ docs containing word )
TF-IDF

Multiply them. Words in every document get IDF = ln(1) = 0.

score = TF × IDF
Analogy: in a pile of cricket match reports, "the" and "match" appear everywhere, so they say nothing. "Hat-trick" appears in only one report, so it tells you what was special about that match.
Try it · click any cell to see the math

Uses the same three documents as the Bag of Words demo above (edit them there). Stopwords are removed.

Notice that words appearing in all three documents score 0, and words unique to one document score highest. scikit-learn uses a slightly smoothed formula, ln((1+N)/(1+df)) + 1, so its numbers differ, but the idea is the same.

Python · scikit-learn 
from sklearn.feature_extraction.text import TfidfVectorizer

tfidf = TfidfVectorizer(stop_words="english")
X = tfidf.fit_transform(docs)
import pandas as pd
print(pd.DataFrame(X.toarray(), columns=tfidf.get_feature_names_out()).round(2))
Lesson 08 · Turning text into numbers

Word Embeddings

BoW and TF-IDF treat every word as unrelated: "happy" and "joyful" are as different as "happy" and "banana". Word embeddings fix this by giving each word a list of numbers (a dense vector, often 100–300 numbers) learned from huge amounts of text, so that words with similar meanings sit close together.

The key idea: "You shall know a word by the company it keeps." Words used in similar sentences ("I drank hot ___") get similar vectors: coffee, tea, chai.

Famous embedding models: Word2Vec (Google, 2013), GloVe (Stanford, 2014) and FastText (Facebook, 2016). The most famous result is that you can do arithmetic with meaning: king − man + woman ≈ queen.

Python · gensim 
import gensim.downloader as api
wv = api.load("glove-wiki-gigaword-100")     # pretrained 100-dim vectors

print(wv["king"][:5])                       # first 5 of 100 numbers
print(wv.most_similar("coffee", topn=3))   # tea, drinks, beer ...
print(wv.most_similar(positive=["king", "woman"], negative=["man"], topn=1))
# [('queen', 0.77)]

Limitation: each word gets exactly one vector. "Bank" in "river bank" and "bank account" is the same vector. Transformers (Lesson 11) solve this with contextual embeddings.

Lesson 09 · Applications

Sentiment Analysis

Sentiment analysis decides whether a piece of text expresses a positive, negative or neutral opinion. Companies use it to read thousands of product reviews, tweets and support tickets automatically.

Two approaches

Lexicon-based (rules)

A dictionary gives each word a score (love = +3, awful = −3). Add up the scores, handling "not" and "very". Example tool: VADER. No training needed.

Machine learning

Train a model on thousands of labeled reviews. It learns patterns itself, including context and sarcasm (sometimes). This is Lesson 10 and 11.

Try the Sarcasm example: the rule-based system says "positive" because it sees "great" and "wonderful". This is exactly why modern systems use machine learning and transformers that read the whole context.

Python · VADER (NLTK) 
from nltk.sentiment import SentimentIntensityAnalyzer
nltk.download("vader_lexicon")
sia = SentimentIntensityAnalyzer()
print(sia.polarity_scores("The food was not bad!"))
# {'neg': 0.0, 'neu': 0.5, 'pos': 0.5, 'compound': 0.43}  → positive
Lesson 10 · Applications

Text Classification

Text classification assigns a label (a category) to a piece of text. Sentiment analysis is one type. Others: spam vs. not spam, news topic (sports / politics / tech), language detection, support-ticket routing.

The usual recipe combines everything so far:

Labeled examples→Preprocess + tokenize→BoW / TF-IDF vectors→Train classifier→Predict new text

A classic beginner model is Naive Bayes. During training it counts how often each word appears in spam and in normal messages. For a new message it asks: "given these words, which label is more probable?" It is called naive because it assumes each word is independent of the others, which isn't true, yet it works surprisingly well.

Real projects use thousands of examples and evaluate on data the model hasn't seen, measuring accuracy, precision and recall. Other common classifiers: Logistic Regression, SVM, and today, fine-tuned transformers.

Python · scikit-learn 
from sklearn.pipeline import make_pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB

texts  = ["win a free iphone now", "are we meeting for lunch", ...]
labels = ["spam", "ham", ...]

model = make_pipeline(TfidfVectorizer(), MultinomialNB())
model.fit(texts, labels)
print(model.predict(["claim your free prize"]))   # ['spam']
Lesson 11 · Modern NLP

Introduction to Transformers

The Transformer is a neural-network design introduced in the 2017 paper "Attention Is All You Need". It powers almost all modern NLP: BERT, GPT, Claude, T5, and Google Translate.

Older models (RNNs, LSTMs) read a sentence one word at a time, left to right, and tended to forget the start of long sentences. Transformers look at all words at once and use a mechanism called self-attention to decide which other words matter for understanding each word.

Analogy: reading "The animal didn't cross the street because it was too tired". To know what "it" means, you glance back at "animal". Self-attention lets every word glance at every other word and decide how much to pay attention to it.
Try it · click a word to see its attention

Illustrative weights. Change the last word from "tired" to "wide" and watch what "it" attends to: a tired thing is the animal, a wide thing is the street.

Inside a Transformer, step by step

Text→Subword tokens→Token embeddings + position info→Self-attention + feed-forward layers (× 12 or more)→Contextual vectors→Task output
  • Positional encoding: because all words are processed together, the model adds a signal telling it each word's position.
  • Multi-head attention: several attention "heads" run in parallel; one may track grammar, another meaning, another references like "it".
  • Contextual embeddings: unlike Word2Vec, "bank" gets a different vector in "river bank" and "bank loan".
  • Pre-training + fine-tuning: first learn language from billions of sentences, then adapt to your small task with a few thousand examples.

Three families

Encoder-only · BERT

Reads the whole sentence in both directions. Trained by filling in blanks ("The [MASK] barked" → dog). Best for understanding: classification, NER, search.

Decoder-only · GPT

Reads left to right and predicts the next token. Best for generating text: chatbots, writing, code.

Encoder–decoder · T5, BART

Encoder reads the input, decoder writes the output. Best for transforming text: translation, summarization.

Python · transformers + datasets 
from datasets import load_dataset
from transformers import (AutoTokenizer, AutoModelForSequenceClassification,
                          TrainingArguments, Trainer)

data = load_dataset("imdb")                              # 1. labeled movie reviews
name = "distilbert-base-uncased"
tok  = AutoTokenizer.from_pretrained(name)                  # 2. matching tokenizer
data = data.map(lambda b: tok(b["text"], truncation=True, padding="max_length"), batched=True)

model = AutoModelForSequenceClassification.from_pretrained(name, num_labels=2)  # 3. pre-trained model
args  = TrainingArguments(output_dir="out", num_train_epochs=1, per_device_train_batch_size=16)

trainer = Trainer(model=model, args=args,
                  train_dataset=data["train"].shuffle(seed=42).select(range(2000)),
                  eval_dataset=data["test"].select(range(500)))
trainer.train()                                             # 4. fine-tune
trainer.save_model("my-sentiment-model")                  # 5. save & share on the Hub
