Part 3 · Data Science

Where does Data Science fit with AI, ML & DL?

AI ⊃ ML ⊃ DL are nested like Russian dolls. Data Science is a separate circle that overlaps them. Part of it uses ML and DL, part of it uses no AI at all, and part of AI has nothing to do with data science.

Correction to the text diagram you pasted: it drew AI completely inside the Data Science box, which would mean all AI is data science. That's not right. A chess engine, a robot's path planner or a self-driving car's control system are AI, but nobody calls them data science. The two overlap; neither contains the other (zone 5 above).
Step 1 · Four kinds of question

What Data Science actually does

Data Science is the whole process of turning raw data into decisions. It asks four kinds of questions, and only the last two usually need ML.

Descriptive
“What happened?”

Sales fell 12% in March in Pune. SQL, dashboards, averages. No ML.

Diagnostic
“Why did it happen?”

Late deliveries doubled after a courier partner changed. Statistics, drill-downs, A/B tests. Usually no ML.

Predictive
“What will happen?”

Which customers will stop ordering next month? ML (random forest, XGBoost) or DL for text/images.

Prescriptive
“What should we do?”

Which customer gets which coupon to save the most money? ML + optimisation + experiments.

Data Science is…

A discipline / process combining statistics, programming and business knowledge to answer questions with data. Output: insight, decisions, sometimes a model.

ML is…

A tool inside AI that learns patterns from data. Data scientists use it when the question is “predict”. ML engineers make it run reliably in production.

Step 2 · The three ingredients

Data Science = maths + code + domain

Maths & statistics: probability, distributions, hypothesis tests, regression. Stops you being fooled by noise.

Programming: Python or R, SQL, pandas, scikit-learn, Git. Lets you work with real data at scale.

Domain knowledge: understanding the business (food delivery, banking, health). Tells you which questions matter and whether an answer makes sense.

Read the overlaps: stats + code without domain = ML that solves the wrong problem. Code + domain without stats = the “danger zone”: confident conclusions from flawed analysis. (Adapted from Drew Conway's well-known data science Venn diagram.)

Step 5 · Who does what

Data roles across the lifecycle

Dark squares = leads that step, light = helps. Steps 1–10 match the wheel above.

Data Scientist

Goal: turn raw data into answers and decisions.
Focus: cleaning, statistics, exploration, modelling, storytelling.
Output: insights, reports, prototype models, recommendations.

ML Engineer

Goal: make models work reliably for millions of users.
Focus: production code, pipelines, MLOps, scaling, latency.
Output: a live API, automated retraining, a working product feature.
